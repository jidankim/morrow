# AXI Phase 0 Feedback/Eval Baseline

Phase 0 is not full AXI compliance. It is the evidence baseline that now has Phase 1 production trace sink smoke coverage, Phase 2 product correlation smoke coverage, and Phase 3 lifecycle replay coverage, while the Phase 4 human approval/correction loop, Phase 5 trajectory eval hardening, and cloud telemetry remain future work.

This ledger maps the six AXI product-rule families to current local evidence and remaining gaps. The diagnostics runbook remains the detailed command and artifact source.

| AXI product-rule family | Current Phase 0 evidence | Still missing |
| --- | --- | --- |
| durable evidence-anchored candidates | Local feedback/eval smoke records candidate feedback events, labels, feature snapshots, metrics, and eval reports from fixture-backed runs. Diagnostics traces remain local artifacts with eval summaries derived from replayable data. Phase 1 production trace sink smoke proves the fake Codex production provider path can write sanitized local JSONL. Phase 2 product correlation is implemented for local candidate and quiet summaries, including retained and deleted diagnostics states, through the local decision-evidence smoke. Phase 3 records local lifecycle evidence for superseded, rescheduled, cancelled, dry-run, commit-idempotent, and replay-run outcomes. | Phase 4 must add human approval/correction outcomes before this becomes an approval workflow. |
| risk-based human approval | Current production flow proposes calendar work through EventKit replay and keeps approval-bypassing mutation paths out of the diagnostics/eval layer. Phase 3 proves local/fake dry-run and commit-idempotency evidence, and real Calendar/Reminders receipts may end as PASS or BLOCKED. | Phase 4 must add the human approval/correction loop, including risk gates, correction capture, and auditable approval outcomes. |
| strict privacy boundaries | The local smokes avoid live vendor backends and real Messages data. Diagnostics exports are sanitized, privacy inspection rejects canary leakage, and feedback snapshots use bounded excerpts plus metadata rather than full private content. Phase 1 production trace sink smoke uses the fake Codex production fixture and rejects an injected raw canary before sanitization. Phase 2 keeps correlation local-only. ## Current Phase 0 Evidence

- `scripts/run-feedback-eval-smoke.sh` proves the local feedback/eval DB smoke with labels, snapshots, metrics, report schema checks, and delete-all preservation.
- `scripts/run-diagnostics-trace-eval-smoke.sh --assert-canary-rejection` proves local diagnostics trace/eval generation and privacy canary rejection without live vendor backends.
- `scripts/run-production-trace-sink-smoke.sh --assert-canary-rejection` proves Phase 1 production provider trace writing through the native fake Codex fixture, sanitized JSONL output, privacy inspection, canary rejection, and diagnostics cleanup receipt without live vendor backends.
- `scripts/run-trace-candidate-correlation-smoke.sh --out-dir .omo/evidence/phase-2-trace-candidate-correlation/final-smoke --assert-canary-rejection` proves Phase 2 local trace-to-candidate/quiet decision correlation, retained trace coverage, deleted diagnostics state handling, privacy inspection, canary rejection, and cleanup receipt without live vendor backends.
- `scripts/run-lifecycle-replay-coverage-smoke.sh --out-dir .omo/evidence/phase-3-lifecycle-replay-coverage/final-smoke --assert-canary-rejection` proves Phase 3 local lifecycle replay coverage, targeted command logs, sanitized trace output, storage readback, lifecycle report, privacy inspection, canary rejection, and cleanup receipt without live vendor backends.
- `scripts/run-lifecycle-real-surface-qa.sh --out-dir .omo/evidence/phase-3-lifecycle-replay-coverage/real-surface` records bounded Calendar and Reminders real-surface receipts. The status contract is `PASS or BLOCKED per surface exits 0; any FAIL exits nonzero`.
- `docs/diagnostics-trace-eval.md` remains the detailed runbook for local layout, smoke commands, privacy inspection, reserved operations, and non-goals.
- `.omo/evidence/phase-2-trace-candidate-correlation/final-smoke/summary.txt` records the completed Phase 2 smoke receipt. Expected artifacts include `summary.txt`, `decision-evidence.json`, `privacy-inspect.txt`, `canary-rejection.txt`, `cargo-decision-evidence.txt`, `npm-decision-evidence.txt`, and `cleanup-receipt.txt`.
- `.omo/evidence/phase-3-lifecycle-replay-coverage/final-smoke/summary.txt` records the completed Phase 3 smoke receipt. Expected artifacts include `.omo/evidence/phase-3-lifecycle-replay-coverage/final-smoke/lifecycle-report.json`, `.omo/evidence/phase-3-lifecycle-replay-coverage/final-smoke/trace.jsonl`, `.omo/evidence/phase-3-lifecycle-replay-coverage/final-smoke/storage-readback.json`, `.omo/evidence/phase-3-lifecycle-replay-coverage/final-smoke/storage-readback-source.json`, `.omo/evidence/phase-3-lifecycle-replay-coverage/final-smoke/storage-readback.sqlite`, `.omo/evidence/phase-3-lifecycle-replay-coverage/final-smoke/privacy-inspect.txt`, `.omo/evidence/phase-3-lifecycle-replay-coverage/final-smoke/canary-rejection.txt`, and `.omo/evidence/phase-3-lifecycle-replay-coverage/final-smoke/cleanup-receipt.txt`.
- `.omo/evidence/phase-3-lifecycle-replay-coverage/real-surface/calendar-status.txt`, `.omo/evidence/phase-3-lifecycle-replay-coverage/real-surface/reminders-status.txt`, and `.omo/evidence/phase-3-lifecycle-replay-coverage/real-surface/cleanup-receipt.txt` record the current real-surface status. No full real-surface pass is claimed because at least one surface is BLOCKED.
- `.omo/evidence/task-1-stabilize-main-feedback-eval-baseline.md` records the current worktree boundary and preserves beta release-distribution files outside this Phase 0 scope.
